# German food morphemes for compound-word decomposition.
#
# "Vollkornbrot" is a single FTS token, so a search for "brot" cannot match it.
# At index time each long token is scanned for the stems below and the matches
# are appended to the indexed text, so the compound stays findable by its parts
# without paying for a trigram index.
#
# Entries are in NORMALIZED form (see lib/core/text/german_normalizer.dart):
# lowercase, ae/oe/ue/ss instead of umlauts. Minimum length 4 — shorter stems
# match far too much ("ei" fires inside Eiweiss, Eintopf and Feige alike).
#
# Longest match wins, so listing both "brot" and "broetchen" is safe.
# Add freely when a search misses; the cost is roughly ten bytes per row.
